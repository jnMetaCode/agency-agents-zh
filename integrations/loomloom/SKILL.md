# 表格批量文生图

先读取同目录 [README.md](README.md) 的命令和限制。脚本在同目录 `scripts/`，由用户的 LoomLoom CLI 执行。此集成需要支持命令执行的 Agent 环境；不要把自身运行环境的工具名写进仓库角色正文。

## 输入

- 通过用户当前健康的 LoomLoom Server 工作；不自动切换平台、账号或索取已有凭证。
- 已有完整提示词原样保留，包括中文、换行与标点。不润色、不翻译、不拼接角色 prompt；如用户明确要求优化，先展示修改稿并确认。
- 使用角色创作新提示词时，先形成可检查的最终画面描述，再填入表格；整段角色定义不是图片提示词。
- 每行一个任务。通用模型版支持当前 Profile 的模型选择，只有提示词端口；用户有精确像素尺寸要求时选择模型对应的 native 规格，不能静默忽略尺寸要求。
- 新规格使用当前 capability resolve 的合同与模型 ID；展示规格并取得远端创建确认后才执行 create。之后下载版本对应的正式 Excel，保留表头与元信息。

## 执行

- 默认使用 Excel，用户可自行填写，也可在明确委托后代填。删除不需要的样例行，展示本次实际行数和所选模型。
- prepare 只校验和报价。展示模板及版本、输入来源、任务行数、费用金额、币种与余额是否足够，再取得本次付费执行确认。不要把模板创建确认当作执行确认。
- 调用 submit 时传入本次确认的金额与币种。输入变化、报价变化或 Server 改变后重新 prepare、确认；不要修改记录绕过检查。
- CLI v0.5.0 的 `estimatedTotalCost.amount` 已是正常货币单位。仅原始 API 明确返回 T 后缀金额时才按其单位解释，不能把 CLI 金额再次除以 10,000,000。
- 网络异常后保留创建记录、报价记录和请求 ID，查询远端状态再处理，不能盲目重跑。
- 仅向用户报告实际返回的 runId、状态与产物。以服务端结果工作簿对齐原始输入，失败行单独核对；不把部分成功说成全部完成。

## 分发

源码可公开分发；每个账号创建自己的私有模板，或通过另行发布的市场 Listing 调用。私有模板、工作簿、报价与运行记录放在忽略的 runtime 目录。默认安装流程不改变。不要自动发布市场商品或更改创作者定价。
